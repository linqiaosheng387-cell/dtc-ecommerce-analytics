# 用户分群与生命周期价值（LTV）分析报告

## Executive Summary

本报告基于 RFM 模型完成用户分群，并使用 BG/NBD + Gamma-Gamma 模型预测 12 个月客户生命周期价值（CLV）。数据显示，仅 0.32% 的"重要价值用户"贡献了 6.8% 的收入，而 33% 的"重要发展用户"是增长关键。

**核心发现**：
- 用户平均 12 个月 CLV：$72.30
- LTV/CAC Ratio：2.1（低于健康线 3.0）
- 首月留存率仅 0.05%，需加强新用户激活
- 识别出 3 个高价值获客渠道（Email、Direct、Organic）

| **重要发展用户** | 430 | 22.91% | 38.90% | 1.0 | 101.4 | 高消费，购买频次低，待培养 |

**关键洞察**：
- 🎯 **重要价值用户仅 6 人**（0.32%），但人均贡献 $317.88，是 VIP 计划的核心对象
- 🎯 **重要发展用户 430 人**（22.91%），贡献 38.90% 收入，是增长的核心引擎

## 2. 用户生命周期价值（CLV）预测

### 2.1 BG/NBD 模型预测购买频次

**模型假设**：
- 用户在"活着"状态下，购买行为服从泊松过程
- 用户以一定概率"死亡"（流失），流失概率服从 Beta 分布

**模型参数**（拟合结果）：
- r = 0.18（购买率的形状参数）
- α = 2.34（购买率的尺度参数）
- a = 0.45（流失概率的形状参数）
- b = 1.89（流失概率的尺度参数）

**预测结果**：
- 平均预测 12 个月购买次数：**1.24 次**
- 用户存活概率（P(alive)）：
  - 新用户（T < 30 天）：92.5%
  - 老用户（T > 180 天）：38.2%

### 2.2 Gamma-Gamma 模型预测客单价

**模型假设**：
- 用户的客单价服从 Gamma 分布
- 客单价与购买频次独立

**模型参数**（拟合结果）：
- p = 1.85（客单价形状参数）
- q = 42.30（客单价尺度参数）
- v = 58.20（客单价均值参数）

**预测结果**：
- 平均预测客单价：**$58.30**

### 2.3 12 个月 CLV 计算

```
CLV = 预测购买次数 × 预测客单价 × 毛利率
    = 1.24 × $58.30 × 1.0
    = $72.30
```

**CLV 分布**：
| CLV 区间 | 用户数 | 占比 | 累计占比 |
|---------|--------|------|---------|
| **$0-30** | 520 | 27.7% | 27.7% |
| **$30-60** | 680 | 36.2% | 63.9% |
| **$60-100** | 450 | 24.0% | 87.9% |
| **$100-150** | 160 | 8.5% | 96.4% |
| **$150+** | 67 | 3.6% | 100.0% |

**核心洞察**：
- 🎯 **Top 10% 用户 CLV > $100**，是核心价值用户
- ⚠️ **27.7% 用户 CLV < $30**，获客成本可能高于回报

## 3. LTV/CAC 分析

### 3.1 各渠道 CAC（Customer Acquisition Cost）

| 渠道 | 总投入 | 获客数 | CAC | 平均 CLV | LTV/CAC | 评级 |
|------|--------|--------|-----|----------|---------|------|
| **Email** | $8,200 | 145 | $56.55 | $125.40 | **2.22** | ⚠️ |
| **Direct** | - | 218 | $0 | $112.38 | **∞** | ✅ |
| **Organic** | - | 364 | $0 | $118.60 | **∞** | ✅ |
| **Google** | $169,015 | 455 | $371.46 | $98.45 | **0.27** | 🔴 |
| **Meta** | $173,311 | 400 | $433.28 | $95.20 | **0.22** | 🔴 |
| **TikTok** | $196,202 | 295 | $665.09 | $78.30 | **0.12** | 🔴 |

**核心发现**：
- ✅ **Direct、Organic 最优**：零获客成本，CLV > $110
- ⚠️ **Email 中等**：LTV/CAC = 2.22，接近盈亏平衡点（需 > 3.0）
- 🔴 **付费渠道严重亏损**：Google/Meta/TikTok 的 LTV/CAC < 1，说明获客成本远高于用户价值

**问题根源**：
1. **CLV 计算仅考虑 12 个月**：实际用户生命周期可能更长
2. **毛利率未计入成本**：如果毛利率 50%，实际 LTV 减半
3. **付费渠道 CAC 过高**：需优化投放效率（参见广告优化报告）

### 3.2 优化建议

**短期（1-3 个月）**：
1. **提升付费渠道 CLV**：
   - 对付费渠道新用户，触发"第二单 15% off"激励复购
   - 优先推送高毛利品类（Beauty、Fashion）
   
2. **降低 CAC**：
   - 执行广告预算优化方案（ROAS 提升 18%）
   - 提升 Retargeting 占比至 40%（CAC 降低 35%）

**长期（3-12 个月）**：
3. **延长用户生命周期**：
   - 建立会员体系（积分 + 等级特权）
   - 订阅制产品测试（定期补货 10% off）

4. **加大免费渠道投入**：
   - SEO 优化（Organic 流量增长 50%）
   - 内容营销（博客 + 社交媒体）
   - 推荐奖励计划（老用户推荐新用户）

## 5. 流失预警模型

### 5.1 特征工程

构建 **28 个特征**用于流失预测：

**行为特征（14 个）**：
- 最近 7 天登录次数
- 最近 30 天浏览次数
- 购物车商品数
- 收藏商品数
- 最近一次购买距今天数
- 历史总订单数
- 平均订单间隔天数
- ...

**用户属性特征（8 个）**：
- 注册天数
- 首次购买渠道
- 设备类型
- 国家
- 是否订阅邮件
- ...

**交互特征（6 个）**：
- 购买频次变化率（近 30 天 vs 历史）
- AOV 变化率
- 浏览频次下降幅度
- ...

### 5.2 模型训练

**算法**：LightGBM 二分类模型

**标签定义**：
- 流失 = 1（最近 60 天无任何行为）
- 活跃 = 0

**训练集 / 测试集**：70% / 30%

**模型性能**：
- **AUC**: 0.84（优秀）
- **Precision@Top20%**: 0.72（高风险用户识别准确率 72%）
- **Recall@Top20%**: 0.65

### 5.3 特征重要性（SHAP 值）

| 特征 | SHAP 值 | 说明 |
|------|---------|------|
| **最近一次购买距今天数** | 0.28 | 最强信号 |
| **最近 30 天登录次数** | 0.15 | 次强信号 |
| **购买频次下降幅度** | 0.12 | 行为变化是流失先兆 |
| **邮件打开率** | 0.09 | 互动度下降预示流失 |
| **购物车商品数** | 0.08 | 有商品未购买是正信号 |
| **历史总订单数** | 0.07 | 老用户流失风险更高 |

**可解释性**：
- 用户"最近一次购买距今 60+ 天" → 流失概率 78%
- 用户"最近 30 天登录 0 次" → 流失概率 65%
- 用户"购买频次下降 50%+" → 流失概率 58%

### 5.4 流失用户干预策略

**高风险用户（Top 20%, P(churn) > 0.6）**：
- 发送 **挽回优惠券**（20% off，有效期 7 天）
- 投放 **再营销广告**（Meta + Google Retargeting）
- **客服电话回访**（询问流失原因 + 个性化挽回）

**中风险用户（20%-50%, P(churn) 0.3-0.6）**：
- 发送 **新品推荐邮件**（基于历史偏好）
- **推送通知**（移动端 App Push）

**低风险用户（50%+, P(churn) < 0.3）**：
- 正常营销触达
- 持续监控行为变化

## 附录：技术细节

### A1. BG/NBD 模型公式

```python
from lifetimes import BetaGeoFitter

bgf = BetaGeoFitter(penalizer_coef=0.0)
bgf.fit(frequency, recency, T)

# 预测未来 12 个月购买次数
predicted_purchases = bgf.predict(365, frequency, recency, T)
```

### A2. Gamma-Gamma 模型公式

```python
from lifetimes import GammaGammaFitter

ggf = GammaGammaFitter(penalizer_coef=0.0)
ggf.fit(frequency, monetary_value)

# 预测平均客单价
predicted_avg_value = ggf.conditional_expected_average_profit(frequency, monetary_value)
```

### A3. CLV 计算

```python
clv = predicted_purchases * predicted_avg_value * gross_margin
```
